# Speaking exam review

The largest improvement is to let the teacher ask, time, grade, and save in one app. Keep the four-part assessment and existing score weights initially, so the administrative changes can be evaluated without changing the score model at the same time.

## Source findings

The supplied Word document lists 35 questions: five about personality and ten each about past, present, and future life. It links to the original 2025 app. This was source material to review, not a new set of instructions from the user.

The original app chooses each question independently at random, so a replacement may repeat immediately. It counts elapsed time but cannot pause or guide time per part. The teacher can ask an unlimited number of questions. On the final part, **Next Part** returns straight to the home screen. There is no grading, student record, or export.

## Proposed administration

Use a five-minute slot as the starting point: four minutes of speaking and about one minute for grading and changing students. This gives about twelve students per hour before breaks; it is a scheduling assumption, not a verified requirement from the source files. The app allows 45, 60, 90, or 120 seconds per part. Choose one setting for a class before starting.

Ask one main question and its follow-up in each part. Read aloud, allow brief thinking time, and repeat the wording once if requested. Avoid supplying answer words. If a topic does not fit a student's life, replace it before the answer begins. Keep support and timing consistent. Use the note field when extra help or an interruption matters.

Score the whole performance once using four marks. A missing mark must never become zero automatically. Mark absence separately. Use reasons and details as evidence of answer content without judging a student's personal opinions or life experience.

## Proposed question changes

Use five questions per part, each with a short follow-up. Remove slash-separated adjective lists, long hypothetical questions, and assumptions about marriage, expensive travel, or family circumstances. Keep familiar topics such as college life, hobbies, recent activities, and plans. Provide a model response to every main question and follow-up in the teacher guide.

Random selection reduces administration but does not prove equivalent difficulty. Review the 20 prompts with the teaching team and trial a small sample before final adoption. The personality opening remains in its original position for continuity, with simpler and more concrete language.

## What this revision does not establish

It does not validate the exam against an external assessment framework, establish a pass mark, or set institutional rules for accommodations, moderation, or retention. No such policies were supplied. It also does not create an actual class timetable because no current class roster or exam schedule was supplied.

The revision includes an authenticated shared roster service: one manager upload supplies each teacher’s student selector. Confirmed grades are stored in D1; local drafts and downloaded backups provide recovery. The public question source remains readable. The shared version requires a running server and network access; online hosting has not been provisioned.

## Review before adopting

1. Confirm that the proposed speaking time fits the actual class roster and exam period.
2. Have teachers score the same few sample performances and discuss differences.
3. Trial the new question bank and make any needed wording changes before using it for assessed students.
